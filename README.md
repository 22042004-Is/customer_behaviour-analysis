📊 Customer Behavior Analytics – Python + SQL + Power BI

A complete data analytics project demonstrating data extraction, cleaning, analysis, SQL querying, and dashboard development using Python, SQL Server, and Power BI.

This project analyzes customer behavior and shopping trends and presents insights through a Power BI dashboard and a presentation created using Gamma.

🚀 Project Steps

1. Load dataset in Python

2. Perform Exploratory Data Analysis (EDA)

3. Clean and transform data

4. Create SQL Database (PostgreSQL/MySQL/SQL Server)

5. Write SQL queries

6. Build Power BI dashboard

7. Create presentation using Gamma
---

📂 Dataset

Retail customer dataset (CSV)

Columns include customer demographics, purchase history, and shopping patterns

Used to analyze trends and derive business insight
